Это плагин для [**Blockbench**](https://www.blockbench.net),
позволяющий экспортировать модели и анимации в форматы **[voxelcore](https://github.com/MihailRis/voxelcore)**
(`.vec3` и `.vcm` для моделей, `.vca` для анимаций, и в`.json` формат скелетов),
намного упрощая моделирование, анимирование и риггинг.

## Как установить?
1) Откройте страницу [релизов](https://github.com/Onran0/voxelbench/releases);
2) Скачайте файл `voxelbench.zip` с последнего релиза;
3) Распакуйте архив в любую папку;
4) В **Blockbench** нажмите `File -> Plugins -> Load plugin from File`
и выберите `voxelbench.js` в распакованной папке.

## Как использовать?

### Для моделей

Нажмите `File -> Export` и выберите подходящий формат, `VCM` или `VEC3`, и настройте все параметры экспортера
под ваши задачи (если нужно). Выбирая `VEC3`, если вы экспортируете модель для скелетной сущности, не забудьте отдельно
экспортировать `.json` скелет через кнопку `Export VC entity skeleton`.

### Для анимаций

Нажмите `File -> Export` и выберите формат `VCA`. Внутри окна выберите в поле нужную анимацию (да, каждую анимацию
придётся экспортировать отдельно, так как формат не поддерживает множественное включение). Также опционально вы
можете включить опцию **запечения анимации** (baking). Это позволит отобразить анимацию визуально более точно если
вы наблюдаете артефакты в обычном режиме, но учтите, что это очень сильно увеличивает вес файла.

## Как сбилдить?

### Гайд для WebStorm

1) Склонируйте репозиторий через интерфейс;
2) Откройте проект **Voxelbench**;
3) Пропишите в терминал `npm run build`;
4) Используйте билд плагина, находящийся по пути `dist/voxelbench/voxelbench.js` относительно корня проекта.
